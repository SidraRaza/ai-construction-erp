# 🏗️ AI Construction ERP — Frontend & Backend Setup

This directory contains the complete full-stack Next.js (App Router) codebase for the **AI Construction ERP**.

## 🚀 Quick Setup Instructions

```bash
# 1. Ensure you are in the frontend directory
cd frontend

# 2. Database schema sync & seeding
npx prisma db push
npx prisma db seed

# 3. Start development server
npm run dev
```

Visit `http://localhost:3000` to access the application.
